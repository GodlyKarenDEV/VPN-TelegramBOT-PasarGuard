# 🤖 ربات تلگرام هوشمند مدیریت و فروش اشتراک V2Ray (متصل به پنل پاسارگاد و MySQL)

یک پلتفرم کامل، پیشرفته و متن‌باز بر پایه **Node.js** جهت خودکارسازی کامل فرایند فروش، تمدید، صدور تست، مدیریت کیف پول و مانیتورینگ سرویس‌های VPN متصل به **پنل پاسارگاد (Pasargad Panel v5.4.1)** با پایگاه داده امن **MySQL**[cite: 7, 9].

---

## 🌟 قابلیت‌ها و امکانات برجسته

* **⚡️ اتصال مستقیم به API پنل پاسارگاد:** ایجاد خودکار ساب‌اسکریپشن، تمدید آنی، حذف از سرور، دریافت لینک هوشمند اتصال و تفکیک اتوماتیک `group_ids`[cite: 9].
* **📦 ۱۲ پلن پیش‌فرض آماده فروش:** ۳ پلن نامحدود (۵ کاربره) و ۹ پلن حجمی (کاربر نامحدود) با امکان تغییر قیمت لحظه‌ای از داخل پنل مدیریت ربات[cite: 5].
* **💰 کیف پول اختصاصی و سیستم حسابداری:** امکان شارژ حساب با پرداخت کارت‌به‌کارت (ارسال فیش و تایید ادمین) و خرید مستقیم پلن‌ها از موجودی کیف پول[cite: 5, 10].
* **🎁 اشتراک تست رایگان ۱۵ دقیقه‌ای:** ساخت کانفیگ تست یک‌بار مصرف برای هر کاربر با قابلیت حذف خودکار اکانت منقضی‌شده از سرور[cite: 6, 9].
* **👥 سیستم رفرال و بازاریابی هوشمند:** لینک دعوت اختصاصی برای هر کاربر همراه با اهدای اشتراک نامحدود ۷ روزه رایگان پس از تکمیل ۳ دعوت موفق[cite: 10].
* **🎫 کدهای تخفیف پیشرفته:** ساخت کدهای تخفیف درصدی (%) یا اعتباری ثابت (تومان) با تعیین مهلت استفاده و اعمال آنی روی پیش‌فاکتور[cite: 5, 10].
* **🔀 انتقال اشتراک به دوستان:** امکان واگذاری مالکیت کانفیگ به کاربر دیگر همراه با محاسبه دقیق زمان باقی‌مانده و صدور فاکتور هوشمند دوطرفه[cite: 10].
* **⏰ مانیتورینگ پس‌زمینه (Cron Job):** پایش مداوم اکانت‌ها و ارسال هشدار خودکار در صورت باقی ماندن کمتر از ۱۰٪ حجم یا کمتر از ۳ روز اعتبار[cite: 6].
* **👑 کنترل پنل مدیریت کامل:** مشاهده آمار زنده درآمد و کاربران، مدیریت موجودی اعضا، ارسال پیام همگانی (به ربات یا کانال) و بررسی منابع سرور (CPU/RAM)[cite: 5].

## 📋 پیش‌نیازهای نصب و راه‌اندازی

پیش از اجرای پروژه مطمئن شوید پیش‌نیازهای زیر روی سرور یا رایانه شما فراهم است:

1. **محیط اجرایی Node.js** (نسخه 18 یا بالاتر) ⬅️ [دانلود Node.js](https://nodejs.org/)
2. **پایگاه داده MySQL** (نسخه 8 یا MariaDB)
3. **ابزار مدیریت نسخه Git** ⬅️ [دانلود Git](https://git-scm.com/)
4. **پنل پاسارگاد فعال** دارای دسترسی ادمین و وب‌سرویس فعال[cite: 9]
5. **توکن ربات تلگرام** (از طریق ربات رسمی [@BotFather](https://t.me/BotFather))

## 🛠 راهنمای نصب و راه‌اندازی صفر تا صد

### گام ۱: کلون کردن مخزن پروژه
ترمینال سرور را باز کرده و دستورات زیر را برای دریافت سورس‌کد اجرا کنید:

```bash
git clone [https://github.com/GodlyKarenDEV/VPN-TelegramBOT-PasarGuard.git](https://github.com/GodlyKarenDEV/VPN-TelegramBOT-PasarGuard.git)
cd VPN-TelegramBOT-PasarGuard
```

---

### گام ۲: نصب پکیج‌ها و وابستگی‌های پروژه
پکیج‌های مورد نیاز را با دستور زیر نصب کنید[cite: 8]:

```bash
npm install
```

---

### گام ۳: ساخت و پیکربندی فایل متغیرهای محیطی (`.env`)
یک نسخه از فایل نمونه `.env.example` را به عنوان فایل اصلی `.env` کپی کنید:

```bash
cp .env.example .env
```

سپس فایل `.env` را با ویرایشگر دلخواه خود (مانند `nano .env`) باز کرده و مقادیر زیر را به دقت تنظیم نمایید:

```env
# =============================================================
# 🤖 تنظیمات اصلی ربات تلگرام
# =============================================================
# توکن دریافتی از BotFather
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ

# نام کاربری ربات بدون @ (جهت ایجاد لینک‌های رفرال)
BOT_USERNAME=YourBotUsername

# آیدی کانال رسمی جهت قفل عضویت اجباری (با @ یا آیدی عددی)
CHANNEL_ID=@YourChannel

# آیدی تلگرام پشتیبان جهت ارتباط کاربران (بدون @)
SUPPORT_USERNAME=YourSupportID

# فهرست یوزرنیم‌های ادمین‌های اصلی با کاما (بدون @)
ADMIN_USERNAMES=admin1,admin2

# =============================================================
# 💳 مشخصات کارت بانکی جهت دریافت فیش واریزی
# =============================================================
CARD_NUMBER=6037990000000000
CARD_HOLDER=نام و نام خانوادگی دارنده حساب

# =============================================================
# 🗄 مشخصات اتصال به پایگاه داده MySQL
# =============================================================
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_NAME=telegram_bot
DB_PASS=your_strong_db_password

# کلید ۳۲ کاراکتری تصادفی جهت رمزنگاری اطلاعات (AES-256)
ENCRYPTION_KEY=Your32CharacterSecretKey12345678

# =============================================================
# 🌐 مشخصات اتصال به پنل پاسارگاد (v5.4.1)
# =============================================================
PANEL_URL=[https://panel.example.com:8000](https://panel.example.com:8000)
PANEL_USER=admin
PANEL_PASS=your_panel_password
PANEL_GROUP_IDS=2
```

---

### گام ۴: راه‌اندازی دیتابیس MySQL
تنها کافی است یک پایگاه داده خالی با همان نامی که در `DB_NAME` وارد کردید در دیتابیس سرور بسازید:

```sql
CREATE DATABASE telegram_bot CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

> **نکته:** نیازی به ایمپورت جداول به صورت دستی نیست؛ ساختار کلیه جدول‌های پایگاه داده (`users`, `orders`, `configs`, `discounts`, `settings`) به شکل کاملاً خودکار در استارت اولیه ربات ساخته می‌شوند[cite: 7].

---

### گام ۵: اجرای اولیه و تست ربات
برای اطمینان از صحت اتصال و کارکرد، دستور زیر را اجرا کنید[cite: 6, 8]:

```bash
npm start
```

اگر اتصال به دیتابیس موفقیت‌آمیز باشد پیام `Bot is ready to work!` را مشاهده خواهید کرد[cite: 6].

---

### گام ۶: روشن نگه داشتن دائمی ربات (با استفاده از PM2)
برای اجرای پایدار و بدون قطعی ربات در پس‌زمینه سرور لینوکس، از ابزار **PM2** استفاده کنید:

```bash
# نصب سراسری PM2
npm install -g pm2

# راه‌اندازی ربات در پس‌زمینه
pm2 start Bot.js --name "pasarguard-bot"

# فعال‌سازی اجرای خودکار پس از ری‌استارت سرور
pm2 startup
pm2 save
```

* **مشاهده لاگ‌های زنده ربات:** `pm2 logs pasarguard-bot`
* **راه‌اندازی مجدد ربات:** `pm2 restart pasarguard-bot`
* **توقف ربات:** `pm2 stop pasarguard-bot`

## 📂 ساختار فایل‌های پروژه

* **`Bot.js`**: هسته اجرایی، هندلر پیام‌ها، سیستم احراز هویت ادمین و جاب مانیتورینگ خودکار پس‌زمینه[cite: 6].
* **`Admin.js`**: کلیه عملیات‌های کنترل پنل مدیریت (گزارش‌گیری، تایید سفارشات، ویرایش قیمت‌ها، ارسال همگانی)[cite: 5].
* **`User.js`**: منوها و جریان‌های مربوط به کاربر (خرید پلن، تست رایگان، کیف پول و انتقال ساب‌اسکریپشن)[cite: 10].
* **`PanelApi.js`**: متدهای احراز هویت و برقراری ارتباط با وب‌سرویس پاسارگاد[cite: 9].
* **`Database.js`**: مدیریت کانکشن پول MySQL و توابع رمزنگاری داده‌ها[cite: 7].
