## 📖 معرفی کلی معماری پروژه

پروژه **VPN-TelegramBOT-PasarGuard** با هدف حذف کامل مداخلات دستی در فروش و توزیع کانفیگ‌های شبکه طراحی شده است[cite: 5, 7, 10]. این سیستم از طریق ارتباط مستقیم با API پنل پاسارگاد نسخه ۵.۴.۱ و کوئری‌های بهینه‌سازی‌شده در MySQL، تمامی مراحل از صدور تست رایگان تا پرداخت، تمدید تجمیعی و تسویه حساب ریالی را مدیریت می‌کند[cite: 6, 7, 8].

معماری این سامانه مبتنی بر تفکیک وظایف (Separation of Concerns) بوده و به صورت ۵ ماژول اصلی پیاده‌سازی شده است تا مقیاس‌پذیری و نگهداری کد در محیط پروداکشن تضمین گردد[cite: 4, 5, 6, 7, 8].

## 📌 قابلیت‌های کلیدی نسخه v2.0.0

- ⚡️ **اتصال هوشمند به پنل پاسارگاد:** دریافت خودکار شناسه‌های گروه فعال (`group_ids`) و رفع کامل خطای `Group not found`[cite: 7].
- 🎭 **موتور سه‌گانه لحن تعاملی ربات (Dynamic Tone Engine):**
  - امکان تنظیم و سوییچ لحظه‌ای ادبیات و متون ربات بین ۳ حالت مختلف از طریق پنل مدیریت:
    - **دوستانه (`friendly`):** ادبیات صمیمی، پرانرژی و همراه با اموجی[cite: 8].
    - **رسمی (`formal`):** ادبیات اداری، کاملاً محترمانه و شرکتی[cite: 8].
    - **حرفه‌ای (`professional`):** لحن بسیار فشرده، داده‌محور و سیستماتیک[cite: 8].
  - تغییر متون بدون نیاز به ری‌استارت پروسس ربات و با ذخیره‌سازی پایدار در جدول `settings`[cite: 4, 6].
- 🔄 **تمدید تجمیعی و افزایشی (Cumulative Renewal):**
  - محاسبه هوشمند مانده حجم و زمان نسوخته اشتراک فعلی و افزودن روزها و گیگابایت پلن جدید به آن بدون سوختن اعتبار قبلی[cite: 7, 8].
  - همگام‌سازی از طریق متد `PUT` روی وب‌سرویس پاسارگاد جهت جلوگیری از رونویسی دیتای کاربر[cite: 7].
- 🔀 **انتقال امن اشتراک (Secure Subscription Transfer):**
  - واگذاری اشتراک به کاربر دیگر همراه با ابطال قطعی لینک در دستگاه فرستنده از طریق حذف ساب‌اسکریپشن قبلی از سرور[cite: 7, 8].
  - صدور فوری یک لینک اتصال جدید با مشخصات باقیمانده برای گیرنده جهت حفظ امنیت[cite: 7, 8].
- 💰 **کیف پول هوشمند و تسویه حساب نقدینگی (Payout System):**
  - شارژ حساب به صورت کارت‌به‌کارت با مبالغ دلخواه و پرداخت مستقیم فاکتورها از موجودی کیف پول[cite: 8].
  - امکان ثبت درخواست برداشت وجه نقدی برای موجودی‌های بالای ۵۰,۰۰۰ تومان همراه با کسر آنی از کیف پول[cite: 8].
  - پنل ویژه ادمین جهت تایید و ثبت شماره پیگیری واریز یا رد درخواست و عودت خودکار وجه به حساب کاربر[cite: 4].
- 🎁 **تست رایگان ۱ ساعته (۶۰ دقیقه):**
  - ساخت آنی اشتراک تست رایگان ۱ ساعته و حذف خودکار کانفیگ منقضی‌شده از سرور پس از ۶۰ دقیقه توسط کرون‌جاب ربات[cite: 5, 8].
- 🔗 **سیستم رفرال و پورسانت نقدی ۱۰ درصدی دائمی:**
  - ثبت قطعی شناسه معرف در ورود اولیه کاربر با دستور `/start`[cite: 5].
  - واریز خودکار ۱۰ درصد از مبلغ تمامی خریدهای زیرمجموعه به عنوان پورسانت نقدی به کیف پول کاربر معرف[cite: 4, 8].
- 🧾 **پشتیبانی کامل از رسیدهای متنوع و چندرسانه‌ای:**
  - دریافت و ثبت فیش‌های پرداختی در قالب عکس، فایل پی‌دی‌اف (Document) و شماره پیگیری متنی بدون مفقودی[cite: 4, 8].
- 🎫 **کدهای تخفیف زمان‌دار:**
  - تعریف تخفیف‌های درصدی یا تومانی با مهلت استفاده مشخص بر حسب روز و کنترل سقف مصرف به ازای هر کاربر[cite: 6, 8].
- ⏱ **پایش خودکار (Cron Monitoring):**
  - بررسی مداوم وضعیت اشتراک‌ها در فواصل ۲ دقیقه‌ای و ارسال هشدار اتمام حجم (زیر ۱۰٪) و انقضای زمان (کمتر از ۳ روز)[cite: 5].
- 🛡 **معماری پایدار و ضد فریز:**
  - فراخوانی سراسری `answerCallbackQuery` جهت جلوگیری از چرخش لودینگ دکمه‌ها در کلاینت تلگرام[cite: 4, 5, 8].
  - گاردهای اعتبارسنجی کامل در ماشین وضعیت جهت جلوگیری از خطای `TypeError: Cannot set step of undefined` پس از ری‌استارت سرور[cite: 3, 8].

## 🚀 راهنمای جامع نصب و پیکربندی پروژه

### ۱. ساخت ربات تلگرام
- در تلگرام وارد ربات [@BotFather](https://t.me/BotFather) شده و دستور `/newbot` را ارسال نمایید.
- نام و یوزرنیم ربات را تعیین کرده و توکن دریافتی را کپی کنید.
- کانال تلگرام خود را ایجاد کرده و ربات را به عنوان مدیر (Admin) در آن عضو کنید تا قفل جوین اجباری به درستی عمل کند.

### ۲. کلون مخزن و نصب پکیج‌ها
ترمینال سرور لینوکس خود را باز کرده و دستورات زیر را وارد کنید[cite: 10]:
```bash
git clone [https://github.com/GodlyKarenDEV/VPN-TelegramBOT-PasarGuard.git](https://github.com/GodlyKarenDEV/VPN-TelegramBOT-PasarGuard.git)
cd VPN-TelegramBOT-PasarGuard
npm install
```

### ۳. آماده‌سازی دیتابیس در MySQL
دیتابیس پروژه را در MySQL بسازید (کلیه جداول و ستون‌های مایگریشن در اولین اجرا به صورت خودکار ایجاد می‌شوند)[cite: 6]:
```sql
CREATE DATABASE IF NOT EXISTS telegram_bot CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### ۴. تنظیم فایل متغیرهای محیطی (`.env`)
فایل الگوی متغیرها را کپی کرده و اطلاعات اختصاصی خود را در آن وارد نمایید[cite: 9]:
```bash
cp .env.example .env
nano .env
```

محتوای فایل `.env`:
```env
# =============================================================
# 🤖 تنظیمات اصلی ربات تلگرام (Telegram Bot Settings)
# =============================================================
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
BOT_USERNAME=YourBotUsername
CHANNEL_ID=@YourChannel
SUPPORT_USERNAME=Karenggr
ADMIN_USERNAMES=admin1,admin2

# =============================================================
# 💳 تنظیمات پرداخت کارت‌به‌کارت (Payment Settings)
# =============================================================
CARD_NUMBER=6037990000000000
CARD_HOLDER=نام صاحب حساب

# =============================================================
# 🗄 تنظیمات پایگاه داده MySQL (MySQL Database Settings)
# =============================================================
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_NAME=telegram_bot
DB_PASS=your_strong_password
ENCRYPTION_KEY=Your32CharacterSecretKey12345678

# =============================================================
# 🌐 تنظیمات اتصال به پنل پاسارگاد (Pasargad Panel v5.4.1)
# =============================================================
PANEL_URL=https://your-panel-domain:8000
PANEL_USER=your_panel_username
PANEL_PASS=your_panel_password
PANEL_GROUP_IDS=1,2
```

### ۵. راه‌اندازی و مدیریت پروسس با PM2
جهت اطمینان از استمرار کار ربات و اجرای خودکار پس از ری‌استارت سرور:
```bash
npm install -g pm2
pm2 start Bot.js --name "pasarguard-bot"
pm2 save
pm2 startup
```

مشاهده لاگ‌های آنلاین ربات:
```bash
pm2 logs pasarguard-bot
```

## 🗄 معماری دیتابیس و تشریح جداول

پروژه به صورت خودکار جداول زیر را در MySQL مقداردهی و مستقر می‌سازد[cite: 6]:

- **`users`:** نگهداری آیدی تلگرام، نام کاربری، مانده کیف پول، نقش، شناسه معرف، تعداد رفرال‌ها و وضعیت تست رایگان[cite: 6].
- **`orders`:** ثبت کلیه تراکنش‌ها اعم از خرید کانفیگ (`config`)، تمدید (`renewal`) و شارژ کیف پول (`wallet_charge`) به همراه رسید متنی یا تصویری[cite: 6].
- **`withdrawals`:** مدیریت درخواست‌های تسویه حساب، شامل مبلغ، شماره شبا/کارت، نام کامل صاحب حساب و وضعیت تایید[cite: 6].
- **`configs`:** ذخیره‌سازی مشخصات پلن‌های حجمی و نامحدود، سقف اتصال، مدت زمان اعتبار و تعرفه‌ها[cite: 6].
- **`discounts`:** مدیریت کدهای تخفیف زمان‌دار با قابلیت تعیین درصد یا مبلغ ثابت و تاریخ انقضا[cite: 6].
- **`settings`:** ذخیره تنظیمات سراسری سیستم از قبیل لحن فعال ربات (`bot_tone`) و متن راهنمای اتصال (`connection_guide`)[cite: 6].

## 🔄 تحلیل جریان‌های کاری (Workflows)

### ۱. چرخه تمدید تجمیعی (Cumulative Renewal Flow)
1. کاربر از بخش «کانفیگ‌های من» گزینه تمدید را برای اشتراک مورد نظر برمی‌گزیند[cite: 8].
2. پیش‌فاکتور با حفظ شناسه ساب صادر شده و پس از پرداخت، متد `createConfigOnPanel` با فلگ `isRenewal = true` اجرا می‌شود[cite: 7, 8].
3. اطلاعات کاربر از API پاسارگاد استعلام شده و مدت زمان پلن جدید به انتهای زمان باقی‌مانده فعلی متصل می‌گردد[cite: 7].
4. حجم جدید به مانده حجم نسوخته کاربر اضافه شده و درخواست به صورت `PUT` در سرور ثبت می‌شود[cite: 7].

### ۲. چرخه انتقال امن اشتراک (Secure Transfer Flow)
1. فرستنده شناسه یا یوزرنیم مقصد را وارد می‌کند[cite: 8].
2. سیستم مانده حجم واقعی و تاریخ انقضای دقیق را از سرور پاسارگاد استخراج می‌کند[cite: 7].
3. ساب‌اسکریپشن قبلی از سرور حذف شده و لینک آن در دستگاه مالک قبلی بلافاصله باطل می‌گردد[cite: 7].
4. ساب‌اسکریپشن جدیدی با مانده زمان و ترافیک واقعی برای کاربر مقصد صادر و ارسال می‌شود[cite: 7, 8].

### ۳. چرخه تسویه حساب (Payout Flow)
1. کاربر در منوی کیف پول، گزینه «💸 درخواست تسویه حساب» را انتخاب می‌کند[cite: 8].
2. در صورت داشتن حداقل ۵۰,۰۰۰ تومان، مبلغ و مشخصات بانکی را وارد می‌کند[cite: 8].
3. موجودی بلافاصله از کیف پول کاربر کسر شده و درخواست در وضعیت `pending` به تمامی ادمین‌ها مخابره می‌شود[cite: 4, 8].
4. با تایید ادمین، اعلان واریز به کاربر ارسال می‌شود؛ در صورت رد درخواست، مبلغ به صورت خودکار به کیف پول کاربر بازگردانده می‌شود[cite: 4].

## ⏱ سیستم مانیتورینگ خودکار (Cron Tasks)

جاب زمان‌بندی‌شده در فایل `Bot.js` هر ۲ دقیقه اجرا شده و موارد زیر را بررسی می‌کند[cite: 5]:
- **حذف تست ۱ ساعته:** اکانت‌های تست رایگان (`plan_id === -1`) پس از اتمام مهلت ۶۰ دقیقه به صورت کامل از سرور پاسارگاد حذف می‌شوند[cite: 5].
- **هشدار اتمام حجم:** با رسیدن حجم باقیمانده به زیر ۱۰٪، پیام اخطار تمدید برای کاربر ارسال می‌گردد[cite: 5].
- **هشدار انقضای زمان:** در ۳ روز پایانی اعتبار اشتراک، هشدار انقضا جهت جلوگیری از قطعی اتصال مخابره می‌شود[cite: 5].

## 🛡 تدابیر امنیتی و خطایابی (Troubleshooting)

| خطا / سناریو | ریشه بروز | راهکار پیاده‌سازی‌شده در کد |
| :--- | :--- | :--- |
| **Cannot set step of undefined**[cite: 3] | کلیک روی دکمه‌های قدیمی پس از ری‌استارت ربات[cite: 8]. | اضافه شدن Guard Clause و هدایت کاربر به منوی اصلی[cite: 8]. |
| **There is no text in the message to edit** | کلیک روی دکمه بازگشت در پیام‌های حاوی تصویر رسید[cite: 4]. | مکانیزم Fallback در `Admin.js` جهت حذف عکس و ارسال مجدد پیام متنی[cite: 4]. |
| **چرخش مداوم لودینگ تلگرام** | عدم پاسخ فوری به کالبک از سمت سرور[cite: 5]. | فراخوانی آنی `bot.answerCallbackQuery(query.id)` در شروع کلیه هندلرها[cite: 4, 5, 8]. |
| **Group not found** | ارسال نشدن یا نامعتبر بودن شناسه‌های گروه[cite: 7]. | تابع `getActiveGroupIds` جهت استعلام خودکار گروه‌های فعال از وب‌سرویس پاسارگاد[cite: 7]. |
